# 1inch

Find 1inch Business API documentation, SDK examples and public Aqua liquidity analytics.

## Capabilities

- Search 1inch API reference material.
- Find SDK examples by language.
- Inspect public Aqua strategy data.

## Access requirements

Public documentation, SDK examples and Aqua strategy analytics are available without a 1inch account. Swaps, order placement, protected Business API calls and account-level debugging require separate 1inch authorization.

## Practical uses

Find the request parameters for a supported chain while developing a 1inch integration, or compare public liquidity data for two Aqua strategies.
