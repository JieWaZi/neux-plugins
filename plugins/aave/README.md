# Aave

Inspect Aave lending markets, public wallet positions and governance across V3 and V4.

## Capabilities

- Compare lending reserves, liquidity and rate history.
- Inspect public wallet positions and health factors.
- Review governance proposals and preview protocol actions.

## Access requirements

Public data and transaction previews are available without an Aave account or API key. The service can prepare unsigned transactions. On-chain execution needs a wallet signature, and submitting an order requires a signed payload.

## Practical uses

Check which markets support a reserve, compare historical rates, or review a specific governance proposal and its voting status.
