# Airtable

在个人访问令牌获准的数据范围内查看和更新记录。查询前可以先核对数据表和字段。令牌具备相应权限时，还可读取记录评论。

## 访问要求

[创建个人访问令牌](https://airtable.com/create/tokens)并指定所需的数据范围。用于汇报时选择只读权限，需要更新记录或表结构时再增加写入权限。Airtable 账号与令牌的权限都会生效。

[官方托管 MCP 服务](https://airtable.com/developers/agents/mcp/getting-started)支持个人访问令牌，本插件使用该方式连接。

## 使用场景

- 汇总数据库中正在进行的项目，找出缺少负责人的记录。
- 在导入其他系统的记录前核对目标数据表的字段。
