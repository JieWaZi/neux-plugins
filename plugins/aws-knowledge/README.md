# AWS Knowledge

Search official AWS documentation and verify service, API and CloudFormation availability by region.

## Capabilities

- Search and retrieve AWS documentation and code examples.
- List regions and check regional availability.
- Look up CDK, CloudFormation and Strands Agents guidance.

## Access requirements

AWS Knowledge uses public AWS material and accepts requests without AWS account credentials. Its scope is documentation and regional availability.

## Practical uses

Check regional support before choosing a deployment region, or find the reference and examples for an AWS API or CDK construct.
