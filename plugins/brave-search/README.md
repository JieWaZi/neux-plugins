# Brave Search

Find public websites, recent news, images, videos, and places. The tools enabled for your Brave Search plan can also provide source context or direct answers.

## Access

Create a [Brave Search API key](https://api-dashboard.search.brave.com/app/keys). Requests use that key and count against the associated plan. Node.js 20 or later is required on the computer running the connection. The package includes a fixed build of the [official Brave Search MCP server](https://github.com/brave/brave-search-mcp-server).

## Examples

- Find primary sources for a public announcement and summarize them with links.
- Compare reporting on the same topic from independent publications.
