# Brave Search

通过 Brave Search 查找公开网站、近期新闻、图片、视频及地点。支持的工具还可提供来源上下文或直接回答，具体取决于账号套餐。

## 访问要求

[创建 Brave Search API 密钥](https://api-dashboard.search.brave.com/app/keys)。请求使用该密钥，并计入对应套餐的用量。运行连接的电脑需要 Node.js 20 或更高版本。本插件包含固定版本的[官方 Brave Search MCP 服务](https://github.com/brave/brave-search-mcp-server)。

## 使用场景

- 查找公开公告的一手来源，附链接汇总主要内容。
- 对比多家独立媒体对同一主题的报道。
