# CoinGecko

Retrieve cryptocurrency prices, historical market data and decentralized exchange pool data from CoinGecko.

## Capabilities

- Look up token prices and market activity.
- Retrieve historical price and volume series.
- Explore decentralized exchange pools.

## Access requirements

CoinGecko offers a public, keyless connection with rate limits. Its tools search SDK documentation and query market data through the SDK. Paid-plan data and higher limits use CoinGecko’s authenticated endpoint.

## Practical uses

Gather historical price and volume data for a market report, or locate decentralized exchange pools for a specific token and network.
