# Composio

Discover and use the actions available in apps linked to Composio Connect. This plugin connects to the MCP service hosted by Composio.

## Connect

This connection requires the Connect consumer API key beginning with `ck_`, available in Sessions & API Key in Composio For You.

Link each app you want to use in Composio. The tools you can invoke depend on those app connections and their permissions.

[Vendor setup guide](https://docs.composio.dev/kb/guide/consumer-project-boundaries-and-auth-selection)

## Practical uses

Review upcoming events from a connected calendar.
