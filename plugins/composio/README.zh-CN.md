# Composio

通过 Composio Connect 查找并使用已连接应用的操作。此插件连接由 Composio 托管的 MCP 服务。

## 连接方式

连接需要以 `ck_` 开头的 Connect 用户密钥，可从 Composio For You 的 Sessions & API Key 获取。

请在 Composio 中连接需要使用的应用。能调用的工具取决于应用连接及其授权权限。

[服务商配置指南](https://docs.composio.dev/kb/guide/consumer-project-boundaries-and-auth-selection)
