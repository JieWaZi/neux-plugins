# Context7

Find indexed library documentation and code examples for the version your project uses.

## Capabilities

- Identify the right library in the documentation index.
- Retrieve version-specific reference material.
- Find examples for an API or a configuration option.

## Access requirements

Public library lookups are available on the anonymous connection and subject to Context7 rate limits. Private libraries and higher quotas require authenticated access.

## Practical uses

Check a framework option against the version pinned in a lockfile, or look up the recommended replacement for a deprecated method.
