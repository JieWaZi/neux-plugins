# Convex

Get Convex guidance for new apps, existing projects and backends that need to scale.

## Capabilities

- Get a runbook for starting a Convex app.
- Plan how to add Convex to an existing project.
- Find scaling guidance for a Convex application.

## Access requirements

The hosted guidance tools run without a Convex account. Working with an actual deployment is handled through Convex’s separate deployment tools and the relevant deployment permissions.

## Practical uses

Plan a backend integration before touching an existing project, or use a scaling runbook to prepare a design review.
