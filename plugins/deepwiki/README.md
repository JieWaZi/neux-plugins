# DeepWiki

Navigate generated documentation for public GitHub repositories and ask questions about their code.

## Capabilities

- List sections in a public repository wiki.
- Read generated repository documentation.
- Ask technical questions about a public codebase.

## Access requirements

The public endpoint works without a Cognition account and covers publicly indexed repositories. Private repositories require Devin access and the corresponding repository permissions.

## Practical uses

Orient yourself in a new open-source project, find where a subsystem is documented, or trace the responsibilities described for two packages.
