# Exa

Search the public web and retrieve page content through Exa.

## Capabilities

- Find web pages relevant to a research question.
- Fetch page content from selected URLs.
- Collect source links for a research summary.

## Access requirements

The public hosted endpoint gives access to the default web search and page-fetching tools without an API key, subject to Exa’s public usage limits.

## Practical uses

Gather supporting pages for a comparison and retrieve the sections needed to verify each claim.
