# Excalidraw

Create sketch-style diagrams and export them to Excalidraw for editing.

## Capabilities

- Create sketches for workflows and architectures.
- Review diagrams in an interactive canvas when supported.
- Export diagrams to Excalidraw for further editing.

## Access requirements

The public diagram endpoint requires no Excalidraw account. Inline rendering and editing require a client that supports MCP Apps. Exported diagrams open in Excalidraw.

## Practical uses

Turn a written workflow into a diagram for review, or sketch how services fit together before documenting an architecture.
