# Firecrawl

Search the web, collect content from public pages, and parse supported documents. Mapping and crawl operations are available when permitted by the Firecrawl team and plan.

## Access

Create a [Firecrawl API key](https://www.firecrawl.dev/app/api-keys). This package uses [Firecrawl's official v2 MCP endpoint with API-key authentication](https://docs.firecrawl.dev/mcp-server/keyless#add-an-api-key) for the plan's tool set. Firecrawl usage limits and charges apply to the connected team.

## Examples

- Collect release notes from public project documentation and summarize changes with source links.
- Extract headings and tables from selected public pages for comparison.
