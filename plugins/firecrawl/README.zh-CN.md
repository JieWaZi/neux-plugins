# Firecrawl

搜索网页、采集公开页面内容，并解析所支持的文档。Firecrawl 团队的套餐和权限允许时，还可查看网站结构或抓取多页内容。

## 访问要求

[创建 Firecrawl API 密钥](https://www.firecrawl.dev/app/api-keys)。本插件使用[官方 v2 MCP 的密钥方式](https://docs.firecrawl.dev/mcp-server/keyless#add-an-api-key)，可用工具及用量由团队套餐决定。

## 使用场景

- 收集公开项目的发布说明，整理变更并附来源链接。
- 提取选定公开页面的标题和表格，便于对比资料。
