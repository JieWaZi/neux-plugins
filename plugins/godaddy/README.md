# GoDaddy

Generate domain name ideas and check public availability through GoDaddy.

## Capabilities

- Check whether a domain name is available.
- Generate alternatives from a name or short description.
- Review listed pricing and registration links.

## Access requirements

Public domain checks and suggestions require no GoDaddy account. Registering a domain or managing account resources requires separate authorization.

## Practical uses

Shortlist names for a new site by checking exact matches and comparing available alternatives and listed prices.
