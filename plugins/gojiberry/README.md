# Gojiberry

Search contacts and lead lists, inspect campaigns and recent outreach conversations, and update records in your Gojiberry account. Adding a contact to a list can enroll the contact in a linked campaign.

## Access

Copy your API key from Account Settings → API in Gojiberry. Available data and actions depend on the account associated with the key. See the [Gojiberry MCP guide](https://help.gojiberry.ai/en/articles/14540015-using-the-gojiberry-mcp-server).

## Use cases

- Identify high-intent prospects in an active lead list.
- Review the steps of an outreach campaign and its contacts.
