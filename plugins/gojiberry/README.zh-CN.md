# Gojiberry

查找联系人和销售线索，查看拓客活动和近期对话，并更新 Gojiberry 账号中的记录。将联系人加入名单可能会使其进入关联活动。

## 访问要求

在 Gojiberry 的 Account Settings → API 中复制 API 密钥。可访问的数据和可执行的操作取决于密钥对应的账号。详见 [Gojiberry MCP 指南](https://help.gojiberry.ai/en/articles/14540015-using-the-gojiberry-mcp-server)。

## 使用场景

- 筛选当前潜客名单中意向较强的联系人。
- 查看某次拓客活动的执行步骤和联系人。
