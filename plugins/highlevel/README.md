# HighLevel

Find CRM records, review opportunities, and check calendars in a HighLevel sub-account. This plugin connects to the MCP service hosted by HighLevel.

## Connect

Open Settings → Private Integrations in the HighLevel sub-account, create a token with the scopes you need, and enter the token and the Location ID from the same sub-account.

For CRM review, start with view scopes. The original universal endpoint exposes a limited set of operations, subject to the token's permissions.

[Private Integrations](https://marketplace.gohighlevel.com/docs/Authorization/PrivateIntegrationsToken/) · [Universal MCP endpoint](https://help.gohighlevel.com/support/solutions/articles/155000008391-highlevel-mcp-for-anthropic-increased-scopes)

## Practical uses

Review open CRM opportunities by pipeline stage.
