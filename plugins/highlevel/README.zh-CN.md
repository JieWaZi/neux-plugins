# HighLevel

搜索 HighLevel 子账号的 CRM 记录、查看销售机会和日历。此插件连接由 HighLevel 托管的 MCP 服务。

## 连接方式

在目标 HighLevel 子账号的「设置 → 私有集成」中创建令牌，勾选需要的权限，再填写该令牌和同一子账号的位置 ID。

如果只需查看 CRM，先为令牌授予查看权限。具有相应修改权限后，服务端会提供额外操作。

[服务商配置指南](https://help.gohighlevel.com/support/solutions/articles/155000005741-how-to-use-the-highlevel-mcp-server)
