# HighLevel

搜索 HighLevel 子账号的 CRM 记录、查看销售机会和日历。此插件连接由 HighLevel 托管的 MCP 服务。

## 连接方式

在目标 HighLevel 子账号的「设置 → 私有集成」中创建令牌，勾选需要的权限，再填写该令牌和同一子账号的位置 ID。

如果只需查看 CRM，先为令牌授予查看权限。通用端点支持的操作范围有限，具体以令牌权限为准。

[私有集成配置](https://marketplace.gohighlevel.com/docs/Authorization/PrivateIntegrationsToken/) · [通用 MCP 端点](https://help.gohighlevel.com/support/solutions/articles/155000008391-highlevel-mcp-for-anthropic-increased-scopes)

## 使用场景

按销售管道阶段查看进行中的商机。
