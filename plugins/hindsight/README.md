# Hindsight

Search and summarize memories across Hindsight Cloud memory banks. This plugin connects to the MCP service hosted by Vectorize.

## Connect

The connection requires an API key from the Connect tab in Hindsight Cloud.

Specify a bank for each task. Calls without a bank use `default`. A bank-scoped key can restrict access to a single bank.

[Vendor setup guide](https://docs.hindsight.vectorize.io/cloud/mcp/)

## Practical uses

Review prior project decisions from a named memory bank.
