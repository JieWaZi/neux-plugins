# Honcho

Find context from earlier sessions and retrieve what Honcho remembers about people and projects. This plugin connects to the MCP service hosted by Plastic Labs.

## Connect

The connection requires a Honcho API key. Specify the workspace when requesting stored context.

Honcho organizes memories by workspace, peer, and session. Use the same workspace ID when you want to retrieve context saved earlier.

[Vendor setup guide](https://honcho.dev/docs/v3/guides/integrations/mcp)

## Practical uses

Check the workspaces available for retrieving stored context.
