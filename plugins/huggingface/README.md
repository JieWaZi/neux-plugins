# Hugging Face

Discover public models, datasets and Spaces, and inspect repository metadata and files on the Hugging Face Hub.

## Capabilities

- Search the Hub for models, datasets and Spaces.
- Inspect model cards and repository metadata.
- Browse files in public Hub repositories.

## Access requirements

The anonymous connection exposes public Hub discovery and reading tools. Access to gated and private repositories, account tools and changes to Hub content depends on authentication and repository permissions.

## Practical uses

Find candidate models for evaluation, check their published licenses and inputs, or inspect the files provided with a public dataset.
