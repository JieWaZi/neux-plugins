# LMCP

Access the computer apps you have shared through LMCP.

## Access requirements

Sign in to LMCP in your browser and approve the access you want to grant. Your account permissions and plan determine which resources and tools you can use.

Set up the LMCP desktop application and enable Cloud Data Forwarding for the apps you intend to share.

[Provider documentation](https://www.local-mcp.com)
