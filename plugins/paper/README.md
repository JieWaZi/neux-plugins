# Paper Desktop

Inspect artboards, selection, styles, and tokens in the open Paper design file. Create and edit layouts, text, and styles. Edits apply directly to the open file.

## Access

Open a design file in Paper Desktop on the same computer as the MCP client. Keep Paper Desktop and the file open to access `http://127.0.0.1:29979/mcp`. See the [Paper MCP guide](https://paper.design/docs/mcp).

## Use cases

- Inspect the typography and spacing of a selected design.
- Create an artboard using the styles from the open file.
