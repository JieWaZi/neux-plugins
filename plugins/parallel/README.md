# Parallel

Search the public web, retrieve source pages and organize evidence for a decision.

## Capabilities

- Search for sources that address a specific question.
- Fetch relevant content from selected web pages.
- Compare options with supporting sources.

## Access requirements

The public connection supports search, page retrieval and evidence-based decisions without an account. Deep research and higher limits require separate Parallel authentication.

## Practical uses

Find source pages for a research brief, retrieve the relevant passages, and compare options against a set of decision criteria.
