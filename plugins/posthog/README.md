# PostHog

Explore product events, inspect feature flags, and query PostHog analytics. This plugin connects to the MCP service hosted by PostHog.

## Connect

The connection requires a PostHog personal API key with access to the relevant projects and permissions.

A personal API key is typically prefixed with `phx_`. For example, reviewing feature flags requires read access to feature flags.

[Vendor setup guide](https://github.com/PostHog/posthog/tree/master/services/mcp#quick-start)

## Practical uses

Compare recent activation trends for an analytics project.
