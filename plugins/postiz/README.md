# Postiz

Review connected social channels and work with posts scheduled in Postiz. This plugin connects to the MCP service hosted by Postiz.

## Connect

The connection requires a Postiz Cloud API key. Postiz provides the Developers settings on Standard and higher plans.

Connect the social channels in Postiz first. When scheduling or publishing, specify the channel and intended publish time.

[Developer settings](https://docs.postiz.com/general/settings/developers) · [MCP setup with an API key](https://docs.postiz.com/mcp/setup)

## Practical uses

Review upcoming posts and their current scheduling status.
