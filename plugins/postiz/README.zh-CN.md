# Postiz

查看 Postiz 已连接的社交渠道，并管理排期中的帖子。此插件连接由 Postiz 托管的 MCP 服务。

## 连接方式

连接需要 Postiz Cloud API Key。开发者设置适用于 Standard 及以上套餐。

请先在 Postiz 中连接社交渠道。排期或发布时，请指定目标渠道和发布时间。

[开发者设置](https://docs.postiz.com/general/settings/developers) · [使用 API Key 连接 MCP](https://docs.postiz.com/mcp/setup)

## 使用场景

核对即将发布的内容及其排期状态。
