# Render

Inspect Render services, deployments, and operational logs in your workspace. This plugin connects to the MCP service hosted by Render.

## Connect

The connection requires a Render account API key. Specify the workspace when querying services or deployments.

The connected key can also permit workspace changes and deployments. Review the target workspace and service before requesting a change.

[Vendor setup guide](https://render.com/docs/mcp-server)

## Practical uses

Review recent deployments and their status before a release.
