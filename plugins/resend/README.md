# Resend

Review delivery information, inspect templates and domains, and prepare or send transactional email in Resend. Available actions depend on the permissions of the API key.

## Access

Create a [Resend API key](https://resend.com/api-keys) with the permissions the work needs. Sending from your own domain requires [domain verification](https://resend.com/docs/dashboard/domains/introduction). The package connects to the [official remote MCP server](https://resend.com/docs/mcp-server) using the API key.

## Examples

- Review recent transactional deliveries and summarize recurring failure reasons.
- Check the configured sender domain and inspect an email template.
