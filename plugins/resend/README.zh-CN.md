# Resend

查看邮件投递信息，检查模板和域名，并在 Resend 准备或发送事务邮件。可用操作依 API 密钥权限而定。

## 访问要求

[创建具备所需权限的 Resend API 密钥](https://resend.com/api-keys)。使用自己的域名发送邮件前，需要[完成域名验证](https://resend.com/docs/dashboard/domains/introduction)。本插件通过密钥连接[官方托管 MCP 服务](https://resend.com/docs/mcp-server)。

## 使用场景

- 核对近期的事务邮件投递记录，归纳重复出现的失败原因。
- 检查已配置的发件域名并查看邮件模板。
