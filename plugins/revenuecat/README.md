# RevenueCat

Review RevenueCat subscription products, offerings, and entitlements for a project. This plugin connects to the MCP service hosted by RevenueCat.

## Connect

The connection requires an API v2 secret key from the RevenueCat project.

Choose the permissions needed for your tasks. Use the project's API v2 secret key to authenticate the hosted MCP server.

[Vendor setup guide](https://www.revenuecat.com/docs/tools/mcp/setup)
