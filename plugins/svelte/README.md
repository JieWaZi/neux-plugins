# Svelte

Look up Svelte and SvelteKit documentation, check component code and prepare examples for the Svelte Playground.

## Capabilities

- Retrieve relevant Svelte and SvelteKit documentation.
- Check Svelte code and get suggested fixes.
- Create a Playground link for a self-contained example.

## Access requirements

The hosted documentation and code tools work without an account. Checking a component sends the provided source code to the hosted server.

## Practical uses

Confirm how a SvelteKit routing convention works, check a component during migration, or share a small reproduction as a Playground example.
