# Tessie

Check vehicle status, battery charge, and recent charging activity from Tessie. This plugin connects to the MCP service hosted by Tessie.

## Connect

The connection requires an access token from Tessie Developer Settings.

Tessie access tokens can also authorize vehicle commands. Remove the token in Tessie Developer Settings to revoke its access.

[Vendor setup guide](https://developer.tessie.com/reference/mcp)

## Practical uses

Check a vehicle's battery level and current charging status.
